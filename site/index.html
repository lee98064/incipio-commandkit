安裝說明

安裝與使用說明書

請依章節順序操作。符合條件的原廠插座可以直接從原廠網頁上傳，不必拆機；其他情況使用燒錄器。安裝完成後，之後的更新都能從網頁進行。

警告：市電有觸電危險（拆機與燒錄時）
  • 拆機與燒錄前，務必拔除插座電源，並確認沒有其他電源接入。
  • 插座接上市電時，切勿連接 USB 燒錄器、UART 或任何接地設備。
  • GD25Q64 快閃記憶體只能使用 3.3 V；部分黑色 CH341A 燒錄器的訊號電壓需先量測確認。
  • 完成後移除燒錄器與所有外接線，裝回外殼，再接上市電。
  • 本韌體為預覽版，並非 Incipio 官方軟體。改裝可能使保固失效，請自行承擔風險。

第2章

首次安裝韌體

依第 1 章選擇的方式操作。兩種方式都會保留 bootloader、MAC、無線校正、原廠 HomeKit 資料與第二槽原廠韌體。

方式 A

原廠網頁上傳（不必拆機）

  1. 下載首次安裝檔

    下載 commandkit-matter-v0.3.1-public-first-install.bin。這是公開共用檔，不含任何裝置金鑰；每台插座第一次開機時會自行產生身分與 Matter 設定碼。

    下載首次安裝檔
  2. 開啟原廠更新頁並核對條件

    插座裝好外殼、接上電源、不要接負載。在路由器的裝置清單找到插座 IP，以瀏覽器開啟 http://插座IP/upload.htm，確認韌體為 10219-1531、Active Bank 2、已勾選 Enable Dual Firmware。不要變更雙韌體設定。

  3. 上傳

    在頁面上方按 Select File 選擇首次安裝檔，再按 Upload。

  4. 等待重新開機

    等待頁面倒數與重新開機，期間請保持供電。不要按「Reboot Form Backup Bank Now」。第一次開機會先產生裝置身分，可能比平常久一些。

  5. 進行首次設定

    出現 CommandKit-Setup-XXXXXX 熱點後，依第 3 章完成設定。

首次安裝檔只用在原廠插座。它會初始化資料區；已安裝本韌體的插座請用管理後台更新，否則會清除配對、管理密碼與累積用電。matter.ota 與 matter-8m-region.bin 也不能在原廠更新頁使用。

原廠網頁安裝完整說明
方式 B

燒錄器

工具會先讀取兩份完整備份並逐位元比對，再依備份產生這台插座專用的映像，最後只寫入第一槽檔案系統。晶片型號、備份內容或核對結果有任何不符，工具都會自動停止。

  1. 斷電並接上燒錄器

    拔除插座電源並拆開外殼，以測試夾夾住 GD25Q64（注意 pin 1 方向），再連接 CH341A。

  2. 讀取兩份備份 
    python3 tools/flash.py backup --session private/read-01 \
  --mains-disconnected --voltage-3v3 --no-other-supply

    三個旗標代表你已確認「已斷開市電、電壓為 3.3 V、沒有其他供電」；工具不會替你量測。備份存放在 private/read-01/，請妥善保存。

  3. 產生這台插座專用的映像 
    python3 tools/flash.py prepare \
  --backup1 private/read-01/before-1.bin --backup2 private/read-01/before-2.bin \
  --release artifacts/releases/matter-8m-region.bin \
  --manifest artifacts/releases/matter-8m-region.json \
  --profile private/outlet-a --output private/matter-target.bin

    此步驟不會接觸硬體。--profile 資料夾保存這台插座的身分；日後重新安裝同一台插座時請沿用，Matter 設定碼才會維持不變。

  4. 只寫入第一槽 
    python3 tools/flash.py write \
  --image private/matter-target.bin --record private/matter-target.bin.json \
  --session private/write-01 \
  --mains-disconnected --voltage-3v3 --no-other-supply

    寫入範圍固定為 0x130000–0x3BFFFF。完成後工具會完整讀回並逐位元核對；顯示 write_verified_not_boot_tested 即表示寫入與核對完成。

  5. 移除燒錄器並裝回外殼

    拆下測試夾與所有接線，裝回外殼後再插上電源。

核對結果不明時，請勿接上市電。保留 session 資料夾與原始備份，可以使用 tools/flash.py restore 取回原本的檔案系統。

第3章

首次設定

接上電源後，插座會開啟設定熱點。指示燈每半秒亮滅一次，表示正在等待設定。

  1. 連接設定熱點

    手機的 Wi-Fi 選擇 CommandKit-Setup-XXXXXX，不需要密碼。此時無法上網屬正常現象，請保持連線。

  2. 開啟設定頁

    若設定頁沒有自動出現，請以瀏覽器開啟 http://192.168.1.254/。

  3. 選擇家中 Wi-Fi

    點選 2.4 GHz 網路並輸入密碼；隱藏網路可手動輸入名稱。插座不支援 5 GHz 與僅限 WPA3 的網路。

  4. 建立管理密碼

    至少 8 個字元，用於登入管理後台。忘記密碼時只能恢復出廠設定。

  5. 保存 Matter 配對碼

    畫面會顯示這台插座專屬的 QR Code 與 11 位數設定碼，請拍照保存。設定碼在重新開機與更新後都不會改變。

第4章

加入智慧家庭

插座預設使用 Matter。

  1. 手機切回家中 Wi-Fi

    插座與手機必須在同一個網路。

  2. 在家庭 app 加入配件

    開啟 Apple 家庭、Google Home 或 Home Assistant，選擇「加入配件」或「新增裝置」。

  3. 掃描 QR Code 或輸入設定碼

    使用第 3 章保存的 QR Code 或 11 位數設定碼，依 app 指示完成。

關於「未認證配件」提示：本韌體使用 Matter 開發測試憑證，家庭 app 可能顯示未認證的提示。各平台對測試裝置的要求不同，請依該平台的官方說明操作。

改用 HomeKit

登入管理後台，在「配對」分頁選擇 HomeKit 並儲存，插座會重新啟動。HomeKit 使用插座原廠標籤上的配對碼。HomeKit 模式下，網頁的即時量測與 kWh 累計會暫停。

    頁面會自動檢查新版本；有新版時，總覽頁會顯示「有新版本可以安裝」。

插座讀取的更新索引就是本網站的 updates/index.json。插座只會安裝簽章正確、型號相符且版本較新的更新包，不會降版。

常見問題

常見問題

設定熱點一直重新出現？

表示插座尚未連上家中 Wi-Fi。請確認選擇的是 2.4 GHz 網路、密碼正確，且路由器沒有設定為僅限 WPA3。重新連接 CommandKit-Setup 後再設定一次。

找不到插座的 IP？

請在路由器的「已連線裝置」或 DHCP 清單中尋找。建議在路由器為插座保留固定 IP，日後較容易開啟管理後台。

更新到一半斷電怎麼辦？

更新器會先寫入資料，最後才補回檔案系統標記並讀回核對。新版啟動失敗時，插座會保留維修入口，可以再安裝較新的修正版；若完全無法開機，需要以燒錄器復原。這不是完整的 A/B 自動回退機制。

我的插座可以不拆機安裝嗎？

原廠韌體為 10219-1531、目前使用 Active Bank 2 且已啟用 Dual Firmware 的插座，可以用第 2 章的方式 A 從原廠網頁上傳。其他版本請使用燒錄器（方式 B）。

可以把 8 MiB 的 BIN 直接整片燒進晶片嗎？

不行。matter-8m-region.bin 是「部分燒錄映像」，只有第一槽檔案系統有內容，其餘區域為 0xFF。必須用工具依你的備份個別化，並只寫入指定範圍。

我的資料會上傳到雲端嗎？

不會。插座的管理與量測都在家中網路內完成。只有在你開啟管理後台時，瀏覽器會向本網站讀取更新索引。

這是 Incipio 的官方韌體嗎？

不是。本專案與 Incipio 無關，是針對自有插座的研究與預覽韌體，請自行評估風險。
