# Wi-Fi 回連分析範圍

日期：2026-10-20，Asia/Taipei。

授權來源：使用者要求研究目前由原廠通道安裝、再升級的自製韌體，哪些情況會造成開機後無法回連 Wi-Fi。

分析對象為本專案 v0.2.4 私人首次安裝映像、已提交的 v0.2.6 簽章 OTA，以及對應來源碼。只在本機離線映像與隔離的暫存 fixture 執行故障注入、MIPS 模擬及比較；不對其他用戶端探測、不寫入插座 Flash、不更改 UniFi 設定。本報告不公開真實 SSID、裝置金鑰、配對碼或 Flash 備份。

成功條件是指出可驗證的啟動失敗路徑，並分清「可重現的設計缺口」與「實體插座此次故障原因」。沒有更新後的開機日誌，不能宣告後者已確定。
