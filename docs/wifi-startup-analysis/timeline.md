# 分析順序

以下均為 2026-10-20；順序號只表示證據取得順序，不代表精確時刻。

1. 綜合先前實體觀察：按鍵仍可切換；UniFi 顯示 Wi-Fi 關聯，SSID 與 VLAN 對應一致，但租約表未找到對應 MAC。顯示的舊 IP 不能視為更新後成功 DHCP 的證據。
2. 從實際 v0.2.4 首次安裝 BIN 與 v0.2.6 OTA 提取啟動腳本及執行檔，驗證 rootfs checksum，逐檔比較 SHA-256。
3. 使用 rabin2 6.2.2 核對 MIPS ELF metadata／imports，追蹤 rcS、身分匯入、設定控制器與 DHCP 呼叫順序。
4. 使用映像內的 BusyBox ash，在隔離 Linux 容器中重放實際腳本，完成 9 個正常／故障對照案例。
5. 執行提取的 production MIPS 身分初始化程式，完成 5 個正常／缺檔／介面失敗案例；相同測試身分的新舊配對資料一致。
6. 重跑舊身分不需亂數的 native／MIPS 測試及既有 7 個啟動測試，保存去識別化結果與報告。未對實體插座再提交更新或配對清除。
