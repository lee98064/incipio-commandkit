# 設定插座指示燈

v0.2.11-preview 在 `http://插座IP:18082/` 的「管理員登入 → 管理設定 → 指示燈」提供控制。HomeKit 與 Matter 使用同一份設定，儲存後約一秒內套用。

| 模式 | 平常表現 |
|---|---|
| 智慧狀態（預設） | 跟隨插座開關，提示設定、連線、配對及異常 |
| 跟隨開關 | 插座開啟時亮、關閉時滅 |
| 反向指示 | 插座關閉時亮、開啟時滅 |
| 耗電指示 | 連續兩次有效功率達 5 W 時閃爍；兩次降至 2 W 以下停止 |
| 恆亮 | 持續亮燈 |
| 恆滅 | 平常熄燈，保留設定、連線、配對與異常提示 |

3–4 W 保持先前負載判定；關閉插座或資料過期會停止耗電閃燈。讀值未知時，跟隨／反向模式不會假裝已知插座狀態。

「尋找插座」會閃燈 15 秒，再恢復模式。HomeKit 辨識要求也閃燈 15 秒；Matter 辨識依控制器指定的持續時間執行。各模式都接受主動尋找。

## 辨認燈號

智慧及恆滅模式顯示以下提示，其餘模式只接受主動尋找。由上往下優先顯示：

| 優先狀態 | 表現 |
|---|---|
| 主動尋找／家庭 App 辨識 | 每四分之一秒亮滅 |
| 服務／MCU 通訊異常 | 每三秒短閃三次 |
| 等待設定／設定熱點開啟 | 每半秒亮滅 |
| Wi-Fi 正在連線或重新連線 | 每兩秒短閃一次 |
| 可進行家庭配對 | 每兩秒短閃兩次 |

開機後保留 60 秒啟動時間，再將缺少／過期的 MCU 回應視為異常。Matter 根據實際配對視窗；HomeKit 根據原廠配對紀錄及 MCU 回應。

## 夜間熄燈與校時

勾選「每天固定時段熄燈」，設定開始與結束時間，再按「儲存燈號設定」。支援跨午夜，預填 23:00–07:00；首次安裝預設關閉排程。夜間抑制平常燈光，保留目前模式原本允許的必要提示與主動尋找。

展開「排程時間與校時」：

- 台灣使用 UTC +8；可調整為 -12 至 +14 小時，每 15 分鐘一格。夏令時間由使用者調整。
- 預設 NTP 伺服器為 `pool.ntp.org`，可改為區網主機名稱或 IPv4 位址。
- 排程啟用且 Wi-Fi 上線後自動校時，成功後每六小時重試校準，失敗隔一分鐘重試。
- IoT 網路不能連外時，登入後按「使用此手機時間校準」。
- 每次開機等有效時間才執行排程；等待時仍依平常模式與提示運作。成功校準後，本次開機可離線繼續計時。校時不改變系統時鐘。

設定與累積 kWh 分別保存；切換協議及一般 OTA 會保留。恢復出廠會清除燈號偏好，回到智慧模式、排程關閉。

## 管理 API

以下介面需有效管理 session；POST 另需 `X-CK-CSRF`，沿用既有同來源檢查與操作互斥。

| 方法／路徑 | 用途與內容 |
|---|---|
| `GET /admin/led` | 讀取模式、排程、校時狀態、服務存活、當前燈號原因 |
| `POST /admin/led` | 文字格式 `CKLED1 MODE ENABLED START END UTC_OFFSET NTP_HOST`；時間與時差單位為分鐘 |
| `POST /admin/led-find` | 空內容，尋找 15 秒 |
| `POST /admin/led-time` | 十進位 Unix UTC 秒數，僅校準本次開機的 LED 排程 |

例如 `CKLED1 smart 1 1380 420 480 pool.ntp.org`。MODE 為 `smart`、`relay`、`inverse`、`load`、`on`、`off`。成功回傳 200；輸入無效 400、未登入或 CSRF 無效 401、其他操作進行中 409、儲存未就緒 503。`GET` 回傳 `service_ready=false` 代表尚未收到近期工作程序狀態，不能當作實體燈號已驗證。

## 實作與驗證

PID1 監督 `ck-led-start`，執行既有靜態 updater 的 `--run-led`。只有此程序設定 GPIO6；GPIO6 為低電位亮燈。Matter 發佈已確認的 MCU 狀態，HomeKit 的限定雜湊 hook 觀察原廠既有讀取，透過 RAM 信箱發佈。串列埠保持單一協議擁有者。

NTP 在具 12 秒期限的獨立子程序處理 DNS／UDP。主程序持續運作，校時失敗不會等待在按鍵、MCU、Wi-Fi 或 HTTP 事件迴圈。簽章 OTA 排入後保持最後 GPIO 電位，經 RAM updater 寫入、讀回與重啟後，由新版重新接手；最後電位不代表更新成功。

詳見[實作驗證報告](2026-10-21_firmware-led-report.md)。目前交付為預覽版；實際 LED、原廠 MFi 與 RF 操作另需原機驗收。
